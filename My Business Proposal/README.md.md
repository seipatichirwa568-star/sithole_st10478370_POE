## 3. Project Overview

Isipho Donations is a South African non-profit organisation website
created to show how donations can be used to support disadvantaged
individuals and families. The organisation works with volunteers,
schools, churches, businesses and members of the community to identify
people and communities that need assistance.

The website gives visitors basic information about the organisation, its
mission and the services it provides. It also includes a gallery to show
donation-related activities and gives visitors a way to contact the
organisation. The main purpose of the website is to make the
organisation easier to understand and to encourage people to get
involved through donating, volunteering or contacting Isipho Donations.

The website was developed as a multi-page website using HTML for the
structure of the pages. HTML is used to structure web content such as
headings, paragraphs, images and links (Mozilla Developer Network,
2025a). CSS is included in the project for the presentation and layout
of the website, while JavaScript can be used to add interactive
functionality as the project develops (Mozilla Developer Network, 2025b;
Mozilla Developer Network, 2025c). Visual Studio Code is being used as
the development environment (Microsoft, n.d.).

## 4. Website Goals and Objectives

The main goals of the Isipho Donations website are:

1.  To introduce visitors to Isipho Donations and explain what the
    organisation does.
2.  To explain the organisation's mission and its focus on helping
    people in need.
3.  To provide information about the services and support offered by the
    organisation.
4.  To display donation-related images through a gallery.
5.  To give visitors a simple way to contact the organisation.
6.  To create a clear and easy-to-navigate website for community
    members, donors and volunteers.
7.  To create an online presence that can be improved as the project
    develops.

## 5. Key Features and Functionality

### Home Page

The Home page acts as the starting point of the website. It introduces
Isipho Donations and provides navigation to the other sections of the
website.

### About Us Page

The About Us page explains what Isipho Donations is and who the
organisation aims to help. It also contains information about the
organisation's mission and how it works with different members of the
community.

### Services Page

The Services page is used to provide information about the type of
assistance and support offered by Isipho Donations.

### Gallery Page

The Gallery page displays donation-related images. The project currently
includes five donation images and an Isipho image.

### Contact Us Page

The Contact Us page provides a section where visitors can find
information on how to communicate with the organisation.

### Navigation

The website uses links between the different HTML pages so that users
can move around the website easily. The main navigation includes:

-   Home
-   About Us
-   Services
-   Gallery
-   Contact Us

### Website Technologies

The project uses:

-   **HTML5** -- used for the structure and content of the website.
-   **CSS** -- used for the appearance, layout and styling.
-   **JavaScript** -- included for interactive functionality as the
    website develops.
-   **Visual Studio Code** -- used as the development environment.
-   **Image files** -- used for the donation gallery and website
    content.
