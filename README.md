2. Project overview
Isipho Donations is a student website concept focused on community support in South Africa. It explains how donations of food, clothing and school supplies, as well as volunteering and partnerships, could help families and communities in need. The website gives visitors information about the project and ways to make enquiries.

Part 1 introduced the HTML pages. Part 2 focused on the external CSS design. In Part 3, I improved the layout and added JavaScript interactions, form validation, SEO features and a deployed website. HTML is used to structure the content, CSS controls the appearance, and JavaScript responds to user actions (MDN Web Docs, s.a.-a; s.a.-b).

Project clarification: This is a student-developed organisation concept. Any real charity activities, physical premises, contact details and photograph permissions must be verified before representing them as confirmed.

6. JavaScript enhancements
6.1 Interactive features
- Mobile menu: A JavaScript click event opens and closes navigation on small screens.
- Gallery lightbox: Selecting a photo opens an enlarged view; visitors can close it again.
- Dynamic services: JavaScript displays services and lets visitors search and sort the available options.
- Floating photographs and reveal effects: CSS animations and JavaScript scroll behaviour improve presentation.
- Interactive map: Leaflet allows visitors to explore the illustrative Pretoria location.
6.2 Contact and Enquiry forms
The Contact form accepts general messages, while the Enquiry form focuses on donation-related questions, volunteering and partnerships.

Form validation uses lecture techniques including addEventListener(), .value.trim(), if statements, field checks, error messages and preventDefault(). JavaScript checks user input before submission. These principles are consistent with client-side form-validation guidance (The IIE, 2026; MDN Web Docs, s.a.-c).

The previously deployed Netlify version was tested: Contact and Enquiry messages appeared in the Netlify Forms dashboard. These test results describe the earlier verified deployment, not a guarantee that every browser or future deployment has been tested (Netlify, s.a.).
